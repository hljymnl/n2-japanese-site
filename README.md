# N2 冲刺网（N2 スプリント）

为 2026年12月6日 JLPT N2 考试打造的全考点备考网站（纯静态，双击 index.html 即可使用，或部署到任意静态托管/GitHub Pages）。

## 知识库规模（对标 JLPT N2 官方知识量）
- **汉字**：1006 个（日本小学 1～6 年级教育汉字，含音读/训读/释义/频率，支持按年级筛选与读音专项测验）
- **词汇**：6938 个（精选核心 633 + N2核心 3093 + N3基础 1595 + N4基础 780 + N5基础 837），均含中文释义与例句
- **文法**：261 个 N2 文法考点，10 大单元分类精讲（接续+意思+例句+注意点），支持搜索
- **能力定位**：读懂日常话题文章、理解较复杂日语，达留学/日企工作门槛

## 题库规模（按 JLPT 官方题型全覆盖）
- **文字・語彙**：192 题（读音/表记/语形成/文脉/近义/用法）
- **文法**：130 题（文法形式判断）
- **排列组合**：30 题（文の組み立て）
- **篇章语法**：20 题（文章の文法）
- **読解**：25 篇 / 68 题（短文/中文/長文・主张/統合理解/情報検索）
- **聴解**：46 题（課題理解/ポイント理解/概要理解/即時応答/統合理解）
- **汉字读音专项**：随机生成（1006 字音读/训读）

## 功能
- **📑 词表资料库**：6000 词表（搜索/按等级/词性筛选/分页）、10 大场景词表（460 词）、高频拟声拟态词（108）、高频外来语（140）、汉字表（1006）
- **🌐 双语菜单**：侧边栏与底部导航全部中/日双语显示
- **📅 今日一练**：每天 20 题（全题型混合），可「换一批」；完成即达成每日任务
- **🌐 全文翻译**：阅读理解一键显示文章与全部题目的中文翻译；每道测验题带「译」按钮
- **👁 查看本题答案**：测试中每道题可即时查看答案+解析；交卷后**全部题目**显示答案+解析
- **5 种测试模式**：全真模拟 30题/30分、文字词汇、文法、読解、聴解专项 + 汉字读音专项
- **单词卡 / 汉字卡 / 文法精讲 / 听力训练 / 阅读理解**：带语音朗读
- **错题本 / 成就 / 打卡**：localStorage 本地保存进度
- **考试情报**：官方构成、得分标准（满分180、合格90、单科≥19/60）、知识量定位
- **冲刺计划**：8/17→12/6 十六周四阶段学习计划

## 使用
1. 双击 `index.html` 打开（推荐 Chrome/Edge/Safari，朗读需联网加载日语语音）
2. 或本地起服务：`python3 -m http.server 8123` 后访问 `http://localhost:8123`
3. 部署：把整个 `n2-japanese-site` 文件夹传到 GitHub Pages / Netlify / Vercel

## 数据来源
- 精选词汇/文法/阅读/听力/模拟题：本站原创整理
- 词汇大全（N2/N3/N4/N5）与汉字库：开源数据集（firavoyage/_anki-jlpt-decks、davidluzgouveia/kanji-data）
